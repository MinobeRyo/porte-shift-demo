# 勤務希望の取り込み 仮公開デモ

GitHub Pagesで動く、ブラウザだけの操作デモです。

- 基本条件を見る：保存済みの名前・経験・区分・勤務量・基本曜日・時間を閲覧
- 基本条件を入力：編集・スタッフ追加後、保存して一覧へ反映
- 文章から取り込み：日付一覧や具体的な時間指定を簡易ルールで読み取り
- 月間希望表：反映内容を確認・手修正

日付だけの希望は基本9:00〜18:00です。対象月とスタッフを選んでお試しください。

## 制限

公開版はAIを使用しません。対応外の文章は確認を求めます。Qwenを使う機能はローカル版で動かします。
入力は各ブラウザのlocalStorageに保存され、他の端末やスタッフとは共有されません。GitHubへの送信も行いません。
Excel出力は準備中です。表は未確定の勤務希望であり、最終シフトではありません。

このリポジトリは公開用ファイルのみを置いています。mainブランチのルートをPagesの公開元に使用します。
