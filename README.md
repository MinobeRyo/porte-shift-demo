# 勤務希望の取り込み 仮公開デモ

GitHub Pagesで動く、ブラウザだけの操作デモです。

- シフト表：7日ずつ、または月全体の希望と不足人数を確認。日付からスタッフの希望を編集
- 希望を入力：文章を確認して保存し、そのまま次のスタッフへ
- スタッフ：基本条件の閲覧・編集
- その他：Excel入出力・変更履歴

入力途中の文章・確認候補は月とスタッフごとに保持します。ブラウザを再読み込みすると未保存の下書きは失われます。

詳しい説明・入力例・履歴の本文は、見出しを押して開けます。

日付だけの希望は基本9:00〜18:00です。対象月とスタッフを選んでお試しください。

## 制限

公開版はAIを使用しません。対応外の文章は確認を求めます。Qwenを使う機能はローカル版で動かします。
入力は各ブラウザのlocalStorageに保存され、他の端末やスタッフとは共有されません。GitHubへの送信も行いません。
Excelは.xlsx形式（5MB以内）に対応します。「対象月・名前・日・可否・開始・終了」の一覧、または名前と日付を見出しにした開始／終了2段の表を読み取ります。任意のExcelレイアウトへの対応ではありません。
出力したExcelは「取込用」シートを編集して再取り込みできます。「勤務希望表」を編集したときは取り込むシートも変更してください。空欄の日は既存の希望を消しません。
表は未確定の勤務希望であり、最終シフトではありません。人数不足も希望ベースの参考です。
